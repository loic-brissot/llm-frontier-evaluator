## Description

Enable and verify end-to-end headless benchmark tests in Docker using the Claude Code CLI (`claude -p`) harness, including model alias resolution, clean-room `.claude/settings.json` isolation hooks, `stream-json` timing/thinking/tool telemetry in `tool_events.py`, and session resume on stalls.
