# Frozen prompt

`PROMPT.txt` is the prompt the gallery copies when you use **Copy the prompt** on [bench.lassence.net](https://bench.lassence.net/). It matches the fenced prompt in the [11 October 2026 post](https://lassence.net/posts/personal-benchmark-3d-atlas-of-paris/).

| Field | Value |
| --- | --- |
| `prompt_id` | `lassence-2026-10-11` |
| SHA-256 | `19387b5a175db8f74b22515f1fce112c653d2286a5ab47fb46c4763176e64c1d` |
| Bytes | 1436 |
| Final newline | No |

The hash is of these exact bytes. A final newline is a different prompt.

Send this file as the only user message in a primary run. Add no instruction before it or after it.

The data links inside the prompt are ODbL sources. This file does not include the data.
